เจดส่งลิงก์ Facebook มา 3 อัน ถามว่า "แบบนี้ดีไหม" — เป็น widget โชว์โควตา Claude คงเหลือบน Windows สุดท้ายเจดชอบตัว **niccolo-sabato/claude-usage-widget** (เกาะ taskbar โชว์แถบสี)

**[Laura]** ตัดสินใจร่วมกับเจดว่า **ไม่เขียนใหม่จากศูนย์ — fork ของ open-source มาต่อยอด** (Scout ค้นเจอว่ามี widget สาย Claude ทำสำเร็จเพียบ, ตัวนี้ MIT + Python+tkinter เข้าสกิลเจดพอดี) ทำงานแบบ plan mode ให้เจดอนุมัติก่อนลงมือ

**[Cinder]** ลงมือตาม 5 ขั้น:
- Clone repo (v2.8.50) เข้ามาที่ `claude-usage-widget/`
- 🔒 **Security audit ก่อนไว้ใจ** — grep network ทั้งไฟล์: ยิงแค่ claude.ai + api.github.com (เช็คอัปเดต), extension ไม่มี fetch/ส่งข้อมูลออกเลย, โค้ด redact `sk-ant-*` ออกจาก log → **ผ่าน**
- รันจากซอร์ส `pythonw src/widget.pyw` (เครื่องเจดพร้อม: Python 3.14, tkinter, Pillow, curl ครบ)
- เจดกรอก session key เอง (เอามาจาก F12 cookie) — วางไม่ติดเพราะแป้นไทย แก้ด้วยสลับ EN แล้ว Ctrl+V
- 🟢 **สำเร็จ**: โชว์ session 31% / weekly 61% ของบัญชี jedsada (plan Ai) ของจริง

**Feasibility เคลียร์แล้ว**: Claude อ่านโควตาได้จริงผ่าน endpoint `/usage` ของหน้าเว็บ (ใช้ session key ไม่ใช่ API key) — ตรงกับทางเลือกที่วางไว้ใน CLAUDE.md. Scope รอบนี้เอา Claude อย่างเดียวก่อน
